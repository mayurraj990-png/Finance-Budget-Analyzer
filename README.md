# Personal Finance & Budget Analyzer

## Overview
The Personal Finance & Budget Analyzer is a Python command-line application that helps users analyze their monthly finances. It takes user income and expense inputs, calculates total spending and savings, categorizes expenses into Needs vs. Wants, evaluates budget health, and provides actionable financial advice.

## Features
- **Expense Categorization:** Separates spending into essential Needs and optional Wants.
- **Financial Metrics:** Calculates total spent, remaining balance, spending percentage, and savings percentage.
- **Budget Health Assessment:** Evaluates savings and assigns a budget status.
- **Smart Insights:** Displays targeted warnings for high spending on dining out or subscriptions.
- **Savings Target:** Recommends a standard 20% savings goal.

## Technologies Used
